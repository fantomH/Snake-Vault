# Snake-Vault Utils

## API

### data_validator

Data validator utility.

#### data_validator.is_valid_password(*password: str*) -> bool

Validates passwords.

### timekeeper

#### timekeeper.time_as_id() -> str

Returns a string representing the time now that can be used as an ID or a timestamp (ex: 20240530111024).
